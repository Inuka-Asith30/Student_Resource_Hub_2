# Student Resource Hub

A lightweight, responsive PHP & MySQL web application designed for students to easily upload, organize, and browse past exam papers, lecture notes, and study materials.


## Setup Instructions

1. Install XAMPP or WAMP.
2. Clone or place this folder (`student_resource_hub_replace`) into your `htdocs` (XAMPP) or `www` (WAMP) directory.
3. Open phpMyAdmin (`http://localhost/phpmyadmin`).
4. Import the `database.sql` file to create the database and tables.
5. Access the application at `http://localhost/student_resource_hub_replace/`.
